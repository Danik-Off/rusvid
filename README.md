# RusVid

Android-приложение на React Native: **единый агрегатор российских
видеоплатформ**. Один поиск — результаты Rutube, VK Видео и Sasflix
вперемешку, один плеер, одна история просмотров.

Сборка полностью локальная: bare React Native, без Expo и облачных сервисов.

---

## Платформы

| Платформа | Вход | Что даёт вход | Поиск | Лента | Категории | Воспроизведение |
|---|---|---|---|---|---|---|
| **Rutube** | на сайте, в приложении | лента подписок | ✅ | ✅ | ✅ | нативно (HLS) |
| **Sasflix** | на сайте, в приложении | материалы по подписке | ✅ | ✅ | ✅ | нативно (HLS) |
| **VK Видео** | на сайте, в приложении | поиск по видео | ✅ | — | — | встроенный плеер VK |

Вход у всех трёх одинаковый: обычная форма входа самой платформы во
встроенном браузере, сессия остаётся в системном хранилище cookie Android.
**Регистрировать приложение, получать ключи и вводить какие-либо
идентификаторы не нужно ни для одной платформы. Пароль пользователя ни в
одном случае не проходит через код приложения.**

Rutube и Sasflix полностью работоспособны и анонимно. У VK анонимно работает
**воспроизведение** (встроенный плеер открывается по одному идентификатору
видео, без API и без сессии), а поиск требует входа — публичного поиска по
видео у VK нет. Обхода платного доступа, DRM или блокировок в проекте нет —
см. [docs/API-RESEARCH.md](docs/API-RESEARCH.md).

## Возможности

- **Единый поиск** — параллельный опрос всех включённых платформ, результаты
  перемешиваются round-robin, у каждой платформы своя пагинация.
- **Устойчивость к сбоям** — падение одной платформы не ломает выдачу
  остальных: сверху появляется полоса «VK: токен истёк», а результаты
  Rutube и Sasflix остаются на экране.
- **Лента и категории** — тренды всех платформ либо одна платформа со своим
  деревом категорий.
- **Плеер** — нативный ExoPlayer для HLS, WebView для embed, автоматический
  откат на веб-плеер платформы при сбое нативного и понятный текст ошибки
  вместо чёрного экрана. Свои элементы управления вместо системных:
  - **мини-плеер** — свайп вниз по кадру сворачивает видео в полоску над
    таб-баром, звук не прерывается, приложением можно пользоваться дальше;
    свайп вбок закрывает;
  - **очередь «Далее»** — список, из которого открыли видео, становится
    очередью: следующий ролик запускается сам, с отменяемым отсчётом;
  - **продолжение просмотра** — видео открывается с той секунды, на которой
    его закрыли, с кнопкой «Сначала»;
  - **жесты** — двойной тап по краю кадра перематывает (серия тапов
    складывается), удержание даёт 2× ускорение, вертикальный свайп в
    полноэкранном режиме меняет громкость и затемнение;
  - **качество, скорость, субтитры, звуковая дорожка** — из шторки, не
    прерывая воспроизведение;
  - **фоновое воспроизведение** с уведомлением, **картинка в картинке**,
    **таймер сна**, повтор и вписывание кадра.
- **Вход во все три платформы** — из настроек, без ввода пароля в приложении:
  OAuth у VK, форма самой платформы во встроенном браузере у Rutube и Sasflix.
- **Лента подписок** — появляется отдельной вкладкой, как только выполнен
  вход в платформу, которая её поддерживает.
- **Проверка платформ** — экран самодиагностики: живые запросы к API каждой
  платформы с таймингами и текстом ошибки на конкретном шаге.
- **Библиотека** — история просмотров с позицией воспроизведения и избранное,
  всё только на устройстве.

## Быстрый старт

```powershell
npm install
npm run android          # debug на подключённое устройство
npm run build:apk        # release APK: arm64-v8a (~20 МБ) и armeabi-v7a (~16 МБ)
```

Требования и установка тулчейна с нуля — [docs/SETUP.md](docs/SETUP.md).

> ⚠️ В `android/gradle.properties` есть блок `RNVideo_useExoplayerHls=true` —
> без него `react-native-video` собирается **без поддержки HLS**, и ни одно
> видео не играет, хотя сборка проходит успешно. Не удаляйте его.

## Структура

```
src/
├── app/          composition root, навигация, App
├── core/         доменная модель, контракт провайдера, агрегатор, ошибки
├── data/         HTTP-клиент, кэш, хранилище, репозитории
├── providers/    rutube / vk / sasflix — по каталогу на платформу
├── features/     экраны и их zustand-сторы
└── ui/           дизайн-токены и переиспользуемые компоненты
```

Зависимости идут строго сверху вниз: `core/` не знает про UI, `providers/`
не знает про экраны, UI не знает ни одного поля Rutube или VK.

## CI и релизы

| Workflow | Когда | Что делает |
|---|---|---|
| [`ci.yml`](.github/workflows/ci.yml) | push в `main`, PR | `typecheck` → `lint` → юнит-тесты |
| [`android.yml`](.github/workflows/android.yml) | PR и push в остальные ветки | собирает debug APK, **проверяет наличие классов ExoPlayer HLS внутри APK**, кладёт артефакт |
| [`release.yml`](.github/workflows/release.yml) | **каждый push в `main` с изменением кода** | считает версию, собирает release APK под `arm64-v8a` и `armeabi-v7a`, коммитит версию, ставит тег `v<version>` и публикует GitHub Release |

### Выпуск версии

Выпускать руками нечего: релиз выходит сам на каждый push в `main`.

```powershell
git commit -am "feat: покадровая перемотка"
git push
```

CI считает версию по коммитам с последнего тега
([tools/next-version.mjs](tools/next-version.mjs), Conventional Commits):

| Коммиты с последнего тега | Шаг |
|---|---|
| `feat!: …`, `BREAKING CHANGE:` в теле | major (`1.2.3` → `2.0.0`) |
| `feat: …` | minor (`1.2.3` → `1.3.0`) |
| всё остальное (`fix`, `chore`, `ci`, …) | patch (`1.2.3` → `1.2.4`) |

Дальше CI сам записывает версию в `package.json`, собирает APK, коммитит
`chore(release): v1.3.0 [skip ci]` обратно в `main`, ставит тег `v1.3.0` и
публикует релиз с файлами `rusvid-1.3.0-arm64-v8a.apk` (нужен практически
всем) и `rusvid-1.3.0-armeabi-v7a.apk` (старые 32-битные устройства).
**После релиза нужен `git pull`** — в `main` появился коммит от бота.

Ручные рычаги, когда автоматики мало:

```powershell
npm run version:next      # показать, какая версия выйдет, ничего не меняя
npm run release:minor     # задать версию явно — она главнее вычисленной
git commit -am "chore: v1.4.0" ; git push
```

- отдельный push без релиза — `[skip release]` в сообщении коммита;
- нужный шаг разово — Actions → Release → Run workflow → `bump`;
- правки только в `*.md` и `docs/` релиз не выпускают.

Версия APK берётся из того же `package.json`
([android/app/build.gradle](android/app/build.gradle)): `versionName` — как есть,
`versionCode` считается как `major*10000 + minor*100 + patch`, потому что
Android умеет сравнивать только целые. Тег, `versionName` и `versionCode`
разъехаться не могут — CI дополнительно сверяет `versionName` собранного APK
с `package.json` и падает при расхождении.

Тег ставится последним — только после того, как APK собран и проверен:
тег без рабочей сборки хуже, чем его отсутствие. Существующий тег
не перезаписывается.

### Почему проверяется HLS

Сборка без `RNVideo_useExoplayerHls=true` проходит успешно, но выдаёт APK,
в котором не играет ни одно видео. Поэтому workflow падает и на потерянном
флаге, и на отсутствии классов в готовом `classes.dex` — проверяется
артефакт, а не только конфигурация.

### Логотип

Знак — треугольник «play», разрезанный на три дольки: три платформы, один
плеер. Вся фирменная графика порождается из одного описания геометрии:

```powershell
npm run icons
```

[tools/gen-icons.mjs](tools/gen-icons.mjs) перерисовывает `assets/logo.svg` и
`assets/logo-mark.svg`, векторные drawable и adaptive icon Android (включая
монохромный слой для тем Android 13+) и растровые mipmap-иконки для API 24–25,
где adaptive icons ещё не работают. Правьте генератор, а не его результат.
Тот же знак внутри приложения рисует
[src/ui/components/Logo.tsx](src/ui/components/Logo.tsx).

## Правовая рамка

Приложение — клиент к публично доступным интерфейсам платформ. Оно не
скачивает видео, не снимает DRM, не обходит подписки и не подменяет рекламу.
Платный контент показывается в списках с пометкой и открывается на сайте
платформы. Вход везде выполняется на странице самой платформы, приложение
работает от лица самого пользователя и его собственной сессии; **чужие
идентификаторы приложений (в том числе официальных клиентов платформ) не
используются**. Внутренние интерфейсы Rutube, Sasflix и веб-клиента VK не
документированы публично и могут измениться в любой момент — в этом случае
правится только маппер соответствующего провайдера.
